# Visualizar Documento

Aplicación web para visualizar documentos PDF de forma interactiva con un perfil de usuario personalizado.

## 📋 Descripción

Este proyecto es una página web que permite visualizar documentos PDF incrustados en un navegador. Incluye una sección de perfil que muestra información del usuario y un botón de descarga del documento.

## 📁 Estructura del Proyecto

```
VisualizarDocumento/
├── index.html           # Página principal
├── style/
│   └── style.css       # Estilos CSS
├── media/
│   └── libro.pdf       # Documento PDF a visualizar
└── README.md           # Este archivo
```

## 🚀 Características

- ✅ Visor PDF embebido en la página
- ✅ Perfil de usuario personalizado
- ✅ Botón de descarga de documento
- ✅ Diseño responsive
- ✅ Interfaz moderna con Font Awesome

## 📱 Requisitos

- Navegador web moderno (Chrome, Firefox, Safari, Edge)
- Conexión a internet (para cargar fuentes de Google y Font Awesome)

## 🛠️ Cómo usar

1. Abre `index.html` en tu navegador web
2. Visualiza el documento PDF en el visor embebido
3. Usa el botón "Descargar PDF" para descargar el archivo

## 🎨 Personalización

Para personalizar el proyecto:

- **Información del perfil**: Edita los valores en la sección `profile-info` del `index.html`
- **Estilos**: Modifica `style/style.css` para cambiar colores y diseño
- **Documento PDF**: Reemplaza `media/libro.pdf` con tu propio archivo

## 📦 Dependencias Externas

- [Google Fonts](https://fonts.googleapis.com) - Fuente Inter
- [Font Awesome](https://cdnjs.cloudflare.com/ajax/libs/font-awesome/6.4.0) - Iconos
